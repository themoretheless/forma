# Контролы интерфейса Forma Studio

Откройте ссылку «Контролы Studio» в заголовке Studio или адрес
`/?project=studio-controls`. Этот проект хранится отдельно от обычного проекта.

`ui/StudioControls.ui` — общий стенд. Файлы Toolbar, Tabs, Tree, Inspector,
Toggles и Diagnostics показывают каждую группу отдельно: откройте файл и
нажмите «Показать UI». Используются непосредственно компоненты из `vector-ui/controls`: PrimaryButton,
SecondaryButton, IconButton, TabButton, TreeItem, TextField, SearchField,
Checkbox, TableRow, Alert и StatusBar. Их палитра, размеры, состояния и Reveal
берутся из Unified Style Guide через общую библиотеку. Самостоятельной темы
Studio и дублирующих визуальных компонентов нет. Изменения исходника сразу видны на стенде.

Доступны кнопки панели и иконок, вкладки, строки дерева, текстовые поля,
строки свойств с источником значения, флажки, диагностика трёх уровней и статус.
Показаны выбранные, изменённые, недоступные и ошибочные состояния.
В режиме «Взаимодействие» работают hover/pressed/focus и редактирование полей.
Выбор вкладок, раскрытие дерева и флажки представлены заданными в разметке
состояниями; прикладная логика Studio к образцам не подключена. События кнопок
попадают в журнал предпросмотра.

Двойной щелчок по части открывает инспектор. В панели «Части и Grid» доступны
итоговые свойства и ссылки на их определения. Для изменения ключа внутреннего
узла можно использовать `override caption { ... }`, если такой ключ объявлен
в выбранном базовом компоненте.

Правки в Studio сохраняются локально в браузере. «Экспорт» сохраняет весь
редактируемый проект в JSON. Файлы в репозитории автоматически не перезаписываются.
