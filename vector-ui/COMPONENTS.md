# Наследование и составной контент

Контракты `prop`/`event`, групповой `match`, `forward`, выражения,
условия, повторители и явные контейнеры — в [спецификации языка](../LANGUAGE.md).

В Forma Studio компоненты ищутся по `components/<Имя>.ui` внутри проекта.
Наследование одиночное, цепочки разрешены, циклы диагностируются.

```css
component ImageButton : Button {
    icon: 'assets/search.svg';
    compact: false;

    override content: match props.compact {
        true => Image {
            source: props.icon;
            width: 20;
            height: 20;
        };
        false => base.content;
    };
}
```

Базовый компонент объявляет `ContentPresenter { key: 'content'; Text { ... } }`.
Только такие элементы служат точками расширения. Любое количество соседних
Frame сохраняется. Несуществующий key — ошибка. `base.content` означает
содержимое непосредственного родителя до текущего override, а не рекурсию.
Внутри `override content` ссылка на другую точку `base.badge` запрещена.
Обычный key не разрешает заменять внутренности компонента.

Приоритет свойств: экземпляр → ближайший наследник → базовый компонент →
резервные значения движка. Пользовательские параметры (`icon`, `compact`)
объявляются значениями по умолчанию. Ноль и false не теряются. Ссылки
`props.*` и `state.*` вычисляются без eval; циклы свойств и отсутствующие
данные диагностируются. match поддерживает литералы, кортежи и `_`, выбирает
первую подходящую ветку. Отсутствие подходящей ветки — ошибка; добавьте `_`.
match также допустим в значениях свойств, не только в override.

## Исполнение

`src/components.js` связывает компоненты и вычисляет выбранный контент при
перекомпиляции/изменении состояния Studio. Примитивный результат передаётся
одинаково в Rust/WASM и в нативный runner. Rust рисует текст и полигоны сам;
DOM-кнопки и браузерный SVG-рендер не используются.

Для форм с `contextType` Studio генерирует Rust-код и запускает ViewModel
проекта; остальные формы запускаются как снимок текущих значений.
[Генерация форм и привязки](BINDINGS.md) включает зависимые свойства, события,
команды и замену контекста.
Сырые файлы наследников не разбираются напрямую низкоуровневым Rust-парсером:
запускайте через Studio, которая выполняет связывание.

При замене содержимого сохраняются фокус внешней кнопки и счётчик кликов
для того же key. Незавершённое нажатие отменяется. Отдельные фокусируемые
элементы внутри контента и анимация замены поддерева пока не поддерживаются.
Анимации Brush базовой кнопки сохраняются.

## Поддерживаемый контент и ограничения

`Frame { radius: 12; clip: true; }` обрезает всё дочернее содержимое по
скруглённому контуру. По умолчанию `clip: false`, `radius: 0`: скругление
фона не запрещает выход дочерних элементов за границы. Радиус ограничен
половиной меньшей стороны. Обрезанные участки корневого Frame не принимают
клики. Вложенные Frame поддерживают независимые области обрезки; соседние
элементы за пределами такой группы не обрезаются.

`overflow: hidden/visible` у корневого векторного Frame сохранён как старый
вариант `clip: true/false`; одновременно указывать оба свойства нельзя.
Прокрутка по-прежнему задаётся отдельным `Scroll`. Нативное окно остаётся
прямоугольным: прозрачные участки сцены компонуются на фоне окна.

- `Text`, `Frame`, `Image`; несколько вложенных Frame и текстов.
- Frame: `columns`, `rows`, `cell`, `row`, `column`, `padding`, `gap`, размеры.
  Треки: числа, `*`, `2*`, `-`/content/auto, проценты. Без cell элемент
  занимает весь Frame; дети без сетки накладываются. Явные размеры ребёнка
  центрируются в выделенной области. `-` использует приближённое измерение
  текста, полноценный layout с shaping пока не реализован.
- Дочерние элементы экземпляра Button передаются в слот `content`.
- Image: путь от корня виртуального проекта к SVG, width/height, color для
  currentColor. Поддерживаются самозакрывающиеся rect, circle, ellipse,
  line, polyline, polygon, fill/stroke и hex-цвета. SVG path, группы,
  transforms, градиенты, внешние ссылки и растровые изображения пока дают
  диагностику. SVG не исполняется и не загружается из сети.
- Сцена содержит один корневой контейнер и до 256 контролов. Вложенные
  Row/Column/Grid/Stack компилируются в расположение контролов; условия и
  повторители могут менять их набор. Старый HTML-рендерер поддерживает
  ограниченный набор встроенных типов.

Примеры: `examples/Button.slots.ui` → `components/Button.ui`,
`examples/ImageButton.component.ui` → `components/ImageButton.ui`,
`examples/ImageButton.ui` → `ui/ImageButtonDemo.ui`,
`examples/search.svg` → `assets/search.svg`.
